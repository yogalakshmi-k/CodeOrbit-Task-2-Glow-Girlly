# 💜 Glow Girlly – Skincare Landing Page

A dreamy and aesthetic skincare brand landing page created as part of **CodeOrbit Tech – Frontend Development Internship (Task 2)**.

Glow Girlly is designed with a soft-girl aesthetic, combining beautiful lilac, baby blue and purple shades to create a visually appealing skincare shopping experience.

## ✨ Features

- Responsive navigation bar
- Attractive hero section with call-to-action button
- Skincare product showcase with product cards
- Beautiful brand story section
- Smooth hover effects and transitions
- Gradient backgrounds and aesthetic colour combinations
- Responsive design for mobile, tablet and desktop screens
- Footer with navigation links

## 🎨 Design Theme

**Brand:** Glow Girlly

**Colour Palette:**
- Lilac
- Baby Blue

- Deep Purple
- Soft Pink

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the Glow Girlly landing page.

## 📱 Responsive Design

The landing page is designed and tested for different screen sizes:

- Mobile – 375px
- Tablet – 768px
- Desktop – 1440px
